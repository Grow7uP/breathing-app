# 呼吸训练小程序

> 微信小程序 · 原生框架 · 零依赖 · 无需联网

基于循证调研选出的主流呼吸训练法打造的通用呼吸引导小程序。内置 **3 种方法**，全部支持**自定义吸气 / 屏气 / 呼气时长**。

## 内置方法

| 方法 | 默认节奏 | 亮点 | 依据强度 |
|---|---|---|---|
| **4-7-8 呼吸法** Relaxing Breath | 吸4s - 屏7s - 呼8s | 哈佛 Weil 博士经典放松呼吸 | 循证 · 机制 |
| **盒式呼吸** Box Breathing | 吸4s - 屏4s - 呼4s - 空肺屏4s | 特种部队同款，减压提专注 | 循证 · 机构背书 |
| **生理性叹息** Physiological Sigh | 深吸2.5s - 补吸0.5s - 长呼6s | 两口气最快降焦虑（斯坦福研究） | 循证 · 最强 |

## 功能
- 顶部横向切换 3 种呼吸法，每种带依据强度徽标与一句话说明
- 呼吸圆动画跟随节奏：吸气放大、屏息保持、呼气缩小（空肺屏息保持最小）
- 阶段文字 + 剩余秒数实时引导
- 循环组数进度点显示（组数可调 1–20）
- **自定义节奏**：对当前方法的每个相位（吸气/屏息/呼气/空肺屏息等）按 0.5 秒步进自由调整，范围 0.5–30 秒，可恢复默认；配置本地持久化（按方法分别记忆）
- 阶段切换轻震动提醒（可关）、开始/暂停/继续/重置

## 如何运行
1. 安装[微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 「导入项目」→ 选择本目录 `breathing-app`
3. AppID 选「测试号」即可编译预览；正式发布需在微信公众平台注册小程序、填入真实 AppID 后上传审核

## 说明
- 呼吸节奏为循证/传统方法的标准推荐值，自定义后请以自身舒适为准
- 本工具仅供放松与冥想练习，不构成医疗建议；练习中若感到头晕、过度换气或不适，请立即停止并恢复正常呼吸
